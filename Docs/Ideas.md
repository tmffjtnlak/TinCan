# 보관 아이디어

> 해 봤거나 떠올렸지만 지금은 빼 둔 것들. 다시 꺼낼 때 여기서 시작한다.

## 코르크 보너스 (10-15, 넣었다가 뺌)

- **무엇:** 병이 깨지면 코르크 마개가 퐁 소리와 함께 가운데 쪽으로 포물선을 그리며 날아간다. 맞히면 세트·배율·정산과 **완전히 별개인 보너스 돈**이 바로 들어온다 (병 터짐 값의 절반). 못 맞히면 그냥 사라진다.
- **왜 좋았나:** 터질 때 옆으로 뭔가 날아가 "쏠 거리"가 하나 더 생긴다. 화면이 조금 채워지고, 노리는 재미(보너스 과녁)가 생긴다.
- **넣었던 방식:** `Cork.cs` (깡통이 아닌 가벼운 물체, 트리거 콜라이더로 총에만 맞음, 공중 깡통 수·세트 끝 판정 밖), `Can.TraitBurst`에서 병일 때 발사, `Gun.Fire` 판정에 코르크, `Game.AddBonus`. 커밋 `9b9bcd4` (되돌림).
- **넓히면:** 깡통 종류마다 "터질 때 날아가는 것" — 현상금의 모자, 묶음의 끈, 다이너마이트의 심지 등. 맞히면 별개 보너스.

## 캐스케이드 궤적 (10-15, 넣었다가 "영 아니다"로 되돌림)

- 맞으면 정해진 포물선 (꼭대기 높이·떨어질 자리 고정), 가운데 건너편으로 넘어가 둘이면 X자로 엇갈림. 아래 맞힘 = 높고 짧게, 위 맞힘 = 낮고 길게.
- 되돌린 이유: 사용자 판단 "영 아니다". 깡통 종류별 궤적(병은 높고 좁게, 파랑은 낮고 길게) 아이디어도 같이 보류.
- 커밋 `b3168f1` (되돌림 `6fcccdd`).

## 마을 / 행동 구역 분할 (10-16, 보류)

- **무엇:** 화면을 둘로. 마을에서 업그레이드·무기 관리, 행동 구역(작은 바)에서 캐릭터가 움직이고 **의자에 앉으면 사격이 시작**된다.
- **보류 이유:** 깡통·현상금이 재밌는지 답을 주지 않고, 걷는 캐릭터·애니메이션·화면 그림이 두세 배. 1챕터로 재미를 확인한 뒤 꺼낸다.
- **싼 대안 (먼저 해 볼 것):** 술집 하나를 마을처럼. 메뉴를 열면 카메라가 그 장소로 간다. 스킬트리 = 주인 카운터, 진열장 = 벽 선반(이미 줌인), 현상금 = 벽의 수배지.
