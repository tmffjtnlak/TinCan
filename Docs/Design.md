# 깡통 (가제, TinCan)

**한 문장:** 무법자가 리볼버로 깡통을 쏴서 공중에 띄운다. 떨어지기 전에 또 쏜다.
**뼈대:** Shelldiver식 조작 인크리멘탈 — 한 가지 동사로 돈을 벌고, 업그레이드하고, 다음 구역을 연다.
**원본 선례:** Hogan's Alley(1984) 트릭 샷 모드. 이걸 이어받은 인디 게임은 2026-10-10 검색 기준 없음.
**가격 모델:** Shelldiver(3,500원, 리뷰 4,800개 98%) / Shoot The Barrels(2,300원, 리뷰 104개 73% — 자동 사격이라 손맛 없음, 우리는 직접 조준).

## 핵심 루프 (사용자 10-10 확정)

플레이어 캐릭터 없음. **화면 자체가 게임판** (Bills Must Be Paid 7,600원·리뷰 5,600개 96% / Scritchy Scratchy 5,750원·리뷰 8,800개 94% 같은 모양).
화면 세 구역: **위 = 타격지역**(하늘), **가운데 = 소환지역**(긴 선반), **아래 = 낙하지역**(모래).
1. 돈을 내고 깡통을 소환한다 (Space). 선반에 올라간다.
2. 쏘면 튀어오른다. 공중에서 맞출 때마다 값 × 연속이 쌓인다.
3. 낙하지역에 떨어지면 쌓인 돈을 **정산**하고 깡통은 사라진다. 돈은 떨어져야 들어온다.

### 세트 (사용자 10-12 확정)

선반 = 준비, 공중 = 실행. 한 흐름이 십몇 초, 이걸 반복한다.
1. **준비**: 선반에 깡통을 놓는다 (돈 씀, 종류 고름). 소환은 공중이 비어 있을 때만.
2. **시작**: 첫 발로 하나 띄우면 소환이 잠긴다. 둘째 깡통은 소환이 아니라 **선반을 쏴서** 올린다 → "둘 띄우면 ×3"이 기술이 된다.
3. **저글링**: 맞출 때마다 금액이 그 순간 배율로 **확정**된다 (탄 기준). 떨어지거나 터지면 맞춘 발 수만큼 **빈 탄피**가 바닥에 쏟아진다. 돈 판자는 아직 그대로 — 세트 안에서는 내 돈이 아니다.
4. **끝**: 공중이 비면 탄피가 돈 판자로 호로록 날아가고, 닿을 때마다 돈이 오른다. "+$N", 최고 세트 기록.
- 점수 = 돈 (따로 안 둔다). 판자에 최고 세트·터뜨림·최고 연속.
- **배율은 세트 끝 점수판**(낚시 게임/오버워치 느낌, 사용자 10-12): 세트 중엔 기본 돈만 쌓이고(깡통 위 "+N"), 공중이 비면 **왼쪽 아래 모래밭 위**(UX: 세트가 끝날 때 눈이 있는 낙하지역 옆, 공중·선반 안 가림, 늘 같은 자리)에 "기본 $N → 저글링 ×3 → 퍼펙트샷 ×1.2 → 저스트리로드 ×1.4 → 합계" 가 한 줄씩 딱딱딱 찍히고, **합계 글자에서 탄피가 주르르륵 쏟아져** 모래밭에 떨어진 것부터 판자로 올라가 돈이 된다. **연출 길이는 점수에 비례** ($10 = 빠르게 몇 줄·탄피 4개, $1,000 = 천천히 전부·탄피 30개, 최고 기록이면 최소 0.7). 깡통이 떨어질 때는 탄피 없이 "+N"만. (폐기: "능력 안 쓰면 배율" — 슬로우가 핵심 재미인데 안 쓰는 쪽으로 몰아서. 배율은 "뭘 해냈나" 셋만.) 저글링 = 세트 중 최대 동시 공중, 퍼펙트샷 = 세트 내내 빗나감 없음, 저스트리로드 = 세트 중 최대 연속 ×(1+0.2n), 최대 ×2. ×1인 줄은 흐리게. 숫자(1.2 / 0.2 / 2)는 임시.
- 탄피: 놋쇠색 빈 것(오른쪽 기둥의 산 탄과 구별), 터뜨린 깡통 것은 금색. 개수 = 발 수, 값은 나눠 싣는다.
- 저주통이 떨어지면 이번 세트 탄피에서 뺏긴다 (보라 링으로 터져 사라짐). 영구 돈은 안 건드린다.
- 자동 사격기는 공중 것만 노린다 (선반을 쏴서 세트를 멋대로 시작하면 안 되니까).
- "최대치 vs 현재값" 문제는 없다: 금액은 쏠 때 박히고 탄피는 나르기만 한다.
상점(스킬 트리)은 플레이 화면과 분리 — Tab으로 연다.
시작 돈 $10, 깡통 $2 (값 1). 한 발만 맞추면 $1 = 손해, 두 발이면 본전, 세 발부터 이익.

## 저주 = 총에 붙는다 (사용자 10-10)

저주는 별도 축이 아니라 **총기류의 변종**. 축은 셋 그대로(무기·깡통·스킬). 네 번째 축은 없다.
- **저주받은 권총** ($250): 값 2배. 대신 맞춘 깡통이 넷에 하나꼴로 **저주통**(보라)이 된다.
- 저주통: 떨어지면 쌓인 돈만큼 **뺏긴다**. 터뜨리면 평소대로 최고치. → 저주 총으로는 무조건 터뜨려야 하고, 못 터뜨릴 것 같으면 안전한 총으로 바꾸는 게 선택.
- 다른 총의 저주 변종(저주 샷건 등)은 GunKind 한 줄. 2주 안엔 권총 하나.
- (폐기) 아이템/부적 축, 소환 때 끼어 나오는 저주 깡통.

## 점수 공식 (예측 가능해야 한다 — 사용자 10-10)

- n번 맞추면 쌓인 돈 = 값 × (1+2+…+n) = **값 × n(n+1)/2**
- 체력 H를 다 채워 터뜨리면 = **값 × H(H+1)** (쌓인 돈 ×2). 깡통 $42 · 병 $60 · 고무 $144 · 모자 $1,100
- 배수(스킬·총·동시 공중)는 그 위에 곱하기만. **동시 공중 배수 = n(n+1)/2: 1개 ×1, 2개 ×3, 3개 ×6, 4개 ×10** (10-11: 둘을 띄우게 유도). 둘 이상이면 화면 위에 큰 배지, 하나만 떠 있으면 "하나 더 띄우면 ×3" 한마디(처음 5번).
- 보여 주기: 공중 깡통 위에 지금 쌓인 돈이 따라다님(마지막 한 발 남으면 주황) · 가게 카드에 "터뜨리면 $N" · 체력 점.
- 플레이어의 계산은 하나: "지금 $15, 두 발 더 맞추면 $42의 2배."
- 거대 깡통(보스 대신 박자): N번 터뜨릴 때마다 큰 깡통(체력 30, 무겁고, 정산 ×5). 같은 세 줄, 숫자만 큼. 끝 화면 조건으로도 씀. 숫자 맞춘 뒤에.

## 깡통 체력 = 터뜨리기 (사용자 10-10)

깡통마다 체력(몇 번 맞으면 터지나). 무한 저글링을 막고, 벌 수 있는 돈의 한계를 정한다.
- 떨어지면: 쌓인 돈 × 정산 배수.
- 체력만큼 맞춰 **터뜨리면: 쌓인 돈 × 정산 배수 × 2 (최고치)**. 파편, 짧은 멈춤, "터짐!".
- 게임 한 문장이 이걸로 바뀐다: **튕겨서 터뜨린다.**
- 깡통 6 / 병 4 / 고무 8 / 모자 10. 깡통 위 흰 점이 남은 체력.

## 저스트 장전 (사용자 10-10, 엔터 더 건전식)

조준점 위에 장전 칸. 노란 슬래시 구간에 R 또는 클릭이면 즉시 장전.
**구간은 고정** (자리 62~74%, 폭 늘 같음 — 사용자 10-10). 성공할수록 다음 장전이 빨라진다(-7%/연속). 어려워지는 건 속도뿐. 실패하면 연속 0 + 이번 장전이 느려진다(+35%).

## 동사 (손맛이 게임)

쏜다 → 깡통이 "탱" 하고 튄다 → 떨어지기 전에 또 쏜다.
공중에 오래 있을수록, 연속으로 맞출수록 배수가 붙는다. 배수가 곧 돈.
첫날 목표: 깡통이 총 맞고 튀는 그 한 순간이 손에 잡히는 것.

## 자동 사격 = 아래에 서는 총들 (사용자 10-12 2판, `AutoGunner.cs`)

선반 옆 기계는 폐기. 스킬트리에서 **자동 리볼버 → 빠른 사격기 / 자동 레버액션 / 자동 샷건**을 뚫을수록 화면 아래(모래 위)에 총이 하나씩 서서 쏜다. 많아질수록 마을 난투. 자리는 가운데를 비우고 좌우로 번갈아(±3.2, ±5.8…). 등장은 아래에서 용수철로 튀어 오름 + 먼지 + "합류".
총마다 **쫓는 성격**: 리볼버 = 조준점 빠름(12), 1.1초, 가까운 것 아무거나 / 레버액션 = 중간(7), 0.8초, 조준점에서 가까운 것 / 샷건 = 느림(4), 2.4초, 가장 낮은(곧 떨어질) 것을 노리고 원 안 전부. 조준점(총마다 색 꺾쇠)이 부드럽게 따라가다 맞물리면 쏘고, **3초 넘게 쫓으면 그 자리에 그냥 쏜다**(빗나갈 수 있음). 오래 쫓을수록 조준이 빨라진다. 총은 조준점을 향해 돌고 왼쪽이면 뒤집힘, 반동은 총열 반대로. 값은 플레이어 총의 절반. 그림은 플레이어 총과 같은 `gun_{id}_side`.

## 총기 가게 = 설명서 종이 (사용자 10-12 스케치, `Booklet.cs` 2판)

배경 = 게임 화면 블러(192×108 렌더텍스처) + 어두운 반투명. 왼쪽 1/6에 총마다 **작은 카드**(총 그림 축소, 보유 갈색·미보유 흐림·저주 보라, 휠 스크롤, 호버 앞으로, 고르면 더 앞으로). 나머지를 **기울어진 종이 두 장**(뒤 파랑 +8°, 앞 흰색 -6°)이 채운다. 열 때 종이가 날아 들어온다(용수철). 앞 종이: 오른쪽 위 이름(볼드 60), 왼쪽 위 총 **밑그림**(어두운 실루엣, 5배), 가운데 설명 두 줄, 왼쪽 아래 수치 알약(탄 수·장전 초, 아이콘 + 알약), 오른쪽 아래 상태. **창을 열고 0.9초 뒤 밑그림 위에 진짜 총이 생겨난다**(흰 실루엣 → 제 색, 작고 기울어진 채 튕기며; 밑그림은 옅어짐; 둥실). 오른쪽 아래 **BUY 카드**(파란 종이 + 알약: 살 수 있으면 노랑, 모자라면 붉게, 보유면 초록 "보유"), 클릭 또는 B = 산다(도장 찍히듯), 1/2 = 장착. 그림 자리: `card_small`(44×32), `paper_sheet`(9슬라이스), `stat_pill`(9슬라이스), 총 `gun_{id}_side`(없으면 리볼버). 1판(책자 펼침)은 폐기. 아티팩트 축은 총 변종으로 흡수. 깡통류는 보류. 업적 해금(잠김)은 아직.

## 시작 이유 (기록)

2026-10-10 새벽~낮. 원숭이(SpaceMonkey)는 추석에 MCP 체험하려고 무료 에셋 보고 시작한 게임이라 마음이 없었다고 사용자가 접음. 조건 "가장 작은 것, 내 손이 들어간 것, 유니티 열기 전에 끝과 날짜를 적는다"로 이 게임 선택. 깡통 아이디어는 화장실에서. 슬라임 퍼즐(중학교 때 게임)은 이게 끝난 뒤의 다음 게임.
