# 방향 (10-16 확정)

## 10-16 오후에 정한 것 (아래보다 우선)
- **총의 다루는 느낌은 고정**: 녹슨 리볼버 0.25초 / 장전 1.2초. 답답함을 강화로 푸는 구조는 버림 → 손맛이 살아남
- **중력도 고정**: 낙하를 느리게 하는 강화는 손맛을 죽인다
- **성장 축 = 슬로우 (데드아이)**: 동체시력의 벽을 넘는 길은 시간뿐. 슬로우가 강해질수록 띄울 수 있는 깡통이 늘고, 그래서 깡통 수가 다시 이득이 된다
- 데드아이 사다리: 숨 참기 → 긴 숨·깊은 숨 → 숨 되찾기 → **표시 후 연발**(만듦) → 표시 늘리기 → 위기의 숨
- 기준: **성장은 기본 실력 이상을 요구하지 않는다** (실력은 보너스, 관문 아님)
- 해 보고 뺀 것: 라운드 모드(60초·책상 복귀, F12에 남아 있음), 약점·도탄(머리로 뺌)
- 조사 자료: `Docs/Research-10-16.md`

후반 정체성 = **현상금**. 깡통으로 벌고, 트리로 강해지고, 현상금을 잡는다.

## 두 재화
- **골드**: 깡통에서. 일반 노드. 얼마든지.
- **증표**: 현상금에서만. 핵심 노드. 현상금을 잡기 전까지의 강함을 막는다.

## 챕터 = 현상금 3
- 앞의 둘은 최종보스 기술을 하나씩 → 패턴을 익히고, 다음 보스를 짐작한다
- 1챕터 안: 구르는 무법자 → 패거리 두목(부하 셋) → 최종(부하 끼고 구른다)

## 정리되는 것
- **총 상점 닫기** → 총 성능은 스킬트리 노드로. 총 바꾸기(1·2번) 없음
- **다른 공격 = 투척물**(3번 칸, 다이너마이트처럼). 핵심 트리에서 해금, 최종보스 기술에서 따온다
- 모독 연쇄·자동사격기: 별로 (코드는 남아 있음)

## 리볼버 한 자루 (정체성)
- 무기는 처음부터 끝까지 **리볼버 하나**. 녹슨 리볼버가 핵심 노드를 열 때마다 모습이 한 단계씩 변한다 (닦임 → 각인 → 저주의 빛)
- 6발·장전 박자 고정. 능력·현상금은 "6발 안에서"로 설계

## 우클릭 능력 = 해금 + 장착
- **해금**: 스킬트리(증표). 예) 집중 중 다이너마이트, 집중 중 표시 → 풀릴 때 연발
- **장착**: 집중 기술 칸 하나에 하나만. 메뉴에서만 바꾼다 (싸움 중 교체 없음)
- 다 해금해도 끼는 건 하나 → 취향 = 공략 (패거리엔 연발, 구르기엔 다이너마이트). 칸 늘리기는 나중에

## 현상금 부르기 = 터뜨린 수
- 자동으로 오지 않는다. **N번 터뜨리면 부를 수 있고, 부르는 때는 플레이어가 고른다**
- 벽의 WANTED 포스터가 터뜨릴 때마다 선명해지고, 다 차면 흔들린다 → 클릭하면 온다
- 놓치면 포스터가 다시 흐려진다 = 잃는 건 시간 (돈은 안 건다: 강화비와 판돈이 다투지 않게)
- 파밍의 위험은 세트 배율 끊김 정도로 충분 (더 아프게 하지 않는다)

## 소환 충전
- 최대 2개, 5초에 하나씩 → 수입이 고정되고, 성공률로 평균을 낸다
- 저글링으로 오래 띄울수록 기다림이 없다 (손맛 = 수입 리듬)

## 열린 질문 = 재미
1. 현상금을 준비하며 깡통 잡는 게 재밌나 (충전 기다림이 생기나)
2. 현상금 자체가 재밌나

→ **1챕터 하나를 끝까지 만들어 20분 해 본다.** 10-24 남의 손 빌드 = 이 1챕터.
