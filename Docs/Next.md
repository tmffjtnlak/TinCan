# 돌아와서 이어 할 것 (10-16 정리)

## 지금 상태 (10-16)

- 흐름: 오프닝(둘러보기 → 첫 깡통 → 좌클릭) → 깡통 소환 노드 → 손 풀기 사슬(간격·장전) → 넓은 선반(첫 저글링) → 3분쯤 우클릭 배우기 → 첫 현상금(체력 8) → 증표·총 가게(리볼버) → 깡통 갈래·진열장
- 술집 주인: 대사 때만 올라옴 (첫 터뜨림, 스킬트리 권유, 우클릭, 현상금, 총 가게). 도형 임시 모습
- 스킬트리: 흑백 시험 중 (`TreeView.Mono`)
- 밸런스 툴: `밸런스보고서.bat`

## 다음 셋 (순서대로)

1. **배경 그림** (사용자): 술집 벽 — 사진 같은 "모인 물건 벽". 액자 자리·술병 선반·걸이는 비워 두고, 배경 명암 폭은 좁게 (깡통이 묻히지 않게). 가운데 위는 덜 빽빽하게.
2. **채워지는 벽** (코드): 그림 칸에 맞춰 잡은 현상금 사진 액자, 연 깡통 술병, 장신구를 놓기. 지금 임시 진열장 선반을 이 방식으로 옮김.
3. **스킬트리 모양**: 흑백 보고 결정 → 노드(깡통 뚜껑·병뚜껑 안) / 세피아 여부.
